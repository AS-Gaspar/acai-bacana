# Trabalho Acadêmico

## Objetivo
  - Criar um banco de dados.
  - Criar duas tabelas que possuam vinculo entre si (Exemplo: Pedidos e itens). 
  - Cada tabela deve possuir no mínimo três colunas (Fora colunas de ID e Timestamp).
  - Implementar um CRUD básico em cima das duas tabelas.
  - Implementar interfaces web para realização das ações (Listar, cadastrar, editar e excluir).
